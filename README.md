# SA:MP (open.mp) Blueprint для Kubek

Готовый blueprint для быстрого развертывания и управления сервером **GTA: San Andreas Multiplayer** на базе [open.mp](https://open.mp) в панели управления **Kubek** (`>= 4.0.0`).

## Возможности

* **Автоматическая установка** — загрузка актуальных сборок `open.mp` напрямую из официального репозитория GitHub.
* **Гибкая настройка** — управление именем сервера, слотами, RCON-паролем и параметрами запуска прямо из интерфейса панели.
* **Генерация конфига** — автоматическое создание `Server/config.json` при установке и его редактирование через встроенный JSON-редактор.
* **Мониторинг и управление** — поддержка статуса сервера и списка игроков (`gamedig:samp`), консоль, бэкапы и файловый менеджер.

## Установка в панель Kubek

1. Скачайте готовый архив `*.kbp` из раздела **Releases** (или соберите его самостоятельно по инструкции ниже).
2. Откройте панель **Kubek** и перейдите в раздел управления блюпринтами.
3. Импортируйте файл `.kbp` и создайте новый игровой сервер.

## Требования к хосту

Так как сервер `open.mp` скомпилирован под 32-битную архитектуру (`x86`), на 64-битных системах Linux (Ubuntu/Debian) должны быть установлены все необходимые 32-битные библиотеки:

```bash
sudo dpkg --add-architecture i386
sudo apt update
sudo apt install -y libc6:i386 libstdc++6:i386 zlib1g:i386 libatomic1:i386 libssl3t64:i386
```

*(Примечание: на более старых версиях Ubuntu 22.04 / Debian 11 вместо `libssl3t64:i386` используйте пакет `libssl3:i386` или `libssl1.1:i386`).*

## Разработка и самостоятельная сборка

### 1. Установка Node.js

Для работы с пакетом типизации (`@kubekpanel/blueprint-sdk`) и автодополнения в редакторе потребуется **Node.js** (рекомендуется LTS-версия).

* **Windows:**
  Скачайте и установите LTS-версию с [официального сайта Node.js](https://nodejs.org) или через менеджер пакетов `winget`:

  ```powershell
  winget install OpenJS.NodeJS.LTS
  ```

* **Linux (Ubuntu/Debian):**

  ```bash
  sudo apt update
  sudo apt install -y nodejs npm
  ```

* **macOS:**

  ```bash
  brew install node
  ```


### 2. Установка зависимостей (опционально, для IDE)

Если вы планируете редактировать `versions.ts`, установите зависимости для корректной работы подсказок TypeScript в редакторе (шаг компиляции не требуется — Kubek выполняет `.ts` напрямую):

* **Windows (PowerShell):**
  > Примечание: в PowerShell рекомендуется использовать `npm.cmd`, чтобы избежать ошибок политики выполнения скриптов (`ExecutionPolicy`).
  ```powershell
  npm.cmd install
  ```
* **Linux / macOS:**
  ```bash
  npm install
  ```

### 3. Упаковка архива `.kbp` в Visual Studio Code

В проекте настроена встроенная задача сборки (`.vscode/tasks.json`), которая автоматически считывает версию из `blueprint.json` и упаковывает `blueprint.json`, `versions.ts` и `icon.png` в готовый пакет.

1. Откройте папку проекта в **Visual Studio Code**.
2. Нажмите сочетание клавиш **`Ctrl + Shift + B`** (или выберите в верхнем меню `Terminal` → `Run Build Task...`).
3. После завершения работы задачи в корне проекта появится готовый файл вида `<имя-папки>-<версия>.kbp`.
